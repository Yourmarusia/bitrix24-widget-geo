# Виджет географии сделок — Битрикс24

Встроенное приложение для Битрикс24 CRM: удобный выбор города, региона и федерального округа прямо в карточке сделки с автодополнением и автозаполнением зависимых полей.

## Логика «заполни одно — остальное подтянется»

| Что вводит менеджер | Что подтягивается автоматически |
|---|---|
| ФО (кнопка) | Поиск регионов и городов фильтруется по ФО (регионы не добавляются автоматически) |
| Регион (поиск) | ФО |
| Город (поиск) | Регион + ФО |

Мультивыбор на всех уровнях. Удаление — только на своём уровне, без каскада.

## Поля в Б24

| Код поля | Название |
|----------|----------|
| `UF_CRM_CITIES_AI` | Город |
| `UF_CRM_REGIONS_AI` | Регион |
| `UF_CRM_DISTRICTS_AI` | Федеральный округ |

## Подключение к Битрикс24

1. **CRM → Настройки → Приложения → Локальные приложения**
2. Добавить приложение:
   - Тип: **Встраиваемое приложение**
   - Размещение: **Карточка сделки (CRM_DEAL_DETAIL_TAB)**
   - URL: `https://yourmarusia.github.io/bitrix24-widget-geo/widget/`
3. Сохранить

## Технологии

- Чистый HTML + JS, без фреймворков
- **BX24.js** — авторизация через сессию пользователя Б24, токены в коде не нужны
- База городов: 835 городов, 85 регионов, 8 ФО

## Архитектура

```
GitHub Pages (виджет + база городов)
        ↓
Битрикс24 Local App (iframe в карточке сделки)
        ↓
BX24.callMethod → crm.deal.update (без вебхука)
```
