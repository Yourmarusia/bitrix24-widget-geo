# Виджет географии сделок — Битрикс24

Виджет для карточки сделки в Битрикс24: три поля географии с автокомплитом и автозаполнением. Нужен для корректной гео-разбивки в Power BI через выгрузку из CRM.

## Три поля

- **Федеральный округ** — 8 кнопок (ЦФО, СЗФО, ЮФО, СКФО, ПФО, УФО, СФО, ДФО)
- **Область / Регион** — поиск с автокомплитом
- **Населённый пункт** — поиск с автокомплитом (826 городов РФ)

## Логика «заполни одно — остальное подтянется»

| Что вводит менеджер | Что подтягивается автоматически |
|---|---|
| ФО (кнопка) | Все регионы этого ФО |
| Регион (поиск) | ФО |
| Город (поиск) | Регион + ФО |

Удаление — только на своём уровне, без каскада. Мультивыбор на всех уровнях одновременно.

## Структура

```
widget/
  index.html        — UI виджета (три секции: ФО кнопки, поиск региона, поиск города)
  app.js            — полная логика: три точки входа, автозаполнение, сохранение в Б24
cities_russia.json  — база: 826 городов, 85 регионов, 8 ФО
generate_plan.js    — генератор Word-документа с планом внедрения (node.js)
План автоматизации географии Битрикс24.docx — готовый план для IT/руководства
```

## Архитектура (без платного сервера)

```
cities_russia.json → GitHub Pages (бесплатный хостинг)
        ↓
Битрикс24 Local App (HTML + JS виджет, iframe в карточке сделки)
        ↓
crm.deal.update → REST API Битрикс24
```
